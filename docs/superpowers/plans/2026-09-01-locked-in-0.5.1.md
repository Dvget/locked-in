# LOCKED IN 0.5.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver LOCKED IN 0.5.1 with corrected run units/trends, simplified and color-aware steps, consistent strength navigation and graphs, training-volume history, and simplified weight ranges.

**Architecture:** Add pure analytics helpers to `TrackingAnalytics` and cover them with SwiftPM tests before wiring SwiftUI views. Keep all persisted models and backup schemas unchanged. Use the existing GitHub macOS workflow for Swift tests and unsigned iPhone device builds.

**Tech Stack:** Swift 5.9, SwiftUI, Swift Charts, SwiftData, XCTest, XcodeGen, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-01-locked-in-0.5.1-design.md`

## Global Constraints

- Preserve the dark LOCKED-IN design and existing navigation.
- Do not add Polar, OAuth, Cloudflare, automatic run import, or configurable training plans.
- Do not change SwiftData models or backup schemas.
- Version must be 0.5.1 build 21.
