# LOCKED IN 0.5.1 Design

## Scope

LOCKED IN 0.5.1 is a corrective UI and analytics release built on version 0.5. It keeps the existing dark design, navigation, SwiftData models, backup format, manual run tracking, and all current history/editing behavior. Polar import and configurable training plans are explicitly excluded.

## Running

- The run chart keeps `Gesamt | Distanz | Pace`, with one series visible at a time.
- `Gesamt` uses the existing combined distance/pace performance index.
- `Distanz` plots raw kilometres and labels the vertical axis in `km`.
- `Pace` plots actual pace and labels the vertical axis in `min/km`; faster pace must appear higher in the graph.
- The headline, current value, percentage change, and color follow the selected series: `Laufentwicklung`, `Distanzentwicklung`, or `Pace-Entwicklung`.
- Each visible run in history shows its combined percentage change against the immediately preceding visible run, using the same visual hierarchy as strength history. The first visible run has no comparison.

## Steps

- The detail picker contains only `Woche | Gesamt`.
- The weekly chart has a minimum ceiling of 10,000 and expands to the next 2,500-step boundary when necessary.
- Weekly bars use daily status colors: up to 4,000 red; 4,001 through 7,499 yellow; at least 7,500 green.
- The weekly goal card colors only the current numerator. `/ 70.000` stays neutral.
- Weekly goal status remains elapsed-day aware: below 70% of required pace red, below 100% yellow, otherwise green.
- The dashboard presents the current week's daily average clearly; the weekly total remains in the detail view.

## Strength

- Strength actions become three full-width rows: prominent `Training nachtragen`, `Einzelne Übungen`, and `Trainingsverlauf`.
- Exercise progression uses a cumulative index starting at 100 so positive changes move upward and negative changes downward.
- Strength statistics gain `Leistung | Volumen`. Volume is the sum of `weight × reps` for completed weighted sets in each workout. Reps-only sets contribute zero. Volume is informational and does not affect performance ratings.

## Weight

- The detail picker contains only `Monat | Jahr | Gesamt`.
- `Monat` is the fallback/default when the previous smart selection would choose `Woche`.

## Release

- Marketing version: `0.5.1`.
- Build number: `21`.
- Existing stored data and backups remain compatible.
